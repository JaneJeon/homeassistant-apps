# Paperless-ngx MCP

Read-only Home Assistant app packaging of [nloui/paperless-mcp](https://github.com/nloui/paperless-mcp) at commit `4ba74570e6161b955fd1f3071ce9472c5b689295`.

The app serves `http://homeassistant:18083/mcp` and connects to the existing Paperless-ngx app. Its Paperless API token is kept in an app password Option. See [DOCS.md](DOCS.md) for setup, source patches, and the read-only tool list.
